# istools-website
Website oficial do plugin ISTools para QGIS

## TiffTools Pro

Aplicativo Windows x64 independente para compressão e reprojeção de arquivos TIFF com o GDAL instalado pelo QGIS. Um dos seus objetivos é facilitar a manipulação de imagens muito pesadas em computadores com menor capacidade de memória.

- [Manual completo e download pelo site](https://irlansouza93.github.io/istools-website/tifftools/)
- [Baixar `TiffToolsPro.exe` pelo GitHub](downloads/TiffToolsPro.exe)
- SHA-256: `FA70844B016466B4102F4CC78CFA4D6950D4E2AA2C65411F4781066DA5BD77D7`

O executável é distribuído separadamente e não integra o pacote do plugin ISTools para QGIS.
