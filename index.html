Domine todas as ferramentas do ISTools com guias práticos e exemplos reais

Instalação do Plugin

1

Download do Plugin

Baixe a versão mais recente do ISTools no GitHub Releases ou instale diretamente pelo repositório de plugins do QGIS.

2

Instalação no QGIS

Vá em Plugins → Gerenciar e Instalar Plugins e procure por "ISTools" ou instale a partir do arquivo ZIP baixado.

3

Ativação das Ferramentas

Após a instalação, as ferramentas aparecerão no menu Vetor → ISTools e na barra de ferramentas personalizada.

Extend Lines

Estende linhas soltas até tocarem outras linhas

Como usar:

  1. Selecione a camada de linhas no painel de camadas
  2. Clique na ferramenta "Extend Lines"
  3. Configure a distância máxima de extensão
  4. Execute a operação e veja as linhas sendo estendidas automaticamente
Dica: Use esta ferramenta para conectar linhas que ficaram com pequenas lacunas durante a digitalização.

Polygon Generator

Gera polígonos a partir de linhas ou áreas ao redor de um ponto

Como usar:

  1. Ative a ferramenta "Polygon Generator"
  2. Clique em um ponto no mapa onde deseja gerar o polígono
  3. A ferramenta identificará automaticamente as linhas ao redor
  4. Um novo polígono será criado na camada de destino
Dica: Ideal para criar polígonos a partir de redes de linhas complexas, como loteamentos ou divisões territoriais.

Bounded Polygon Generator

Gera polígonos limitados por um quadro de referência

Como usar:

  1. Defina uma camada com o quadro limitador (frame)
  2. Selecione as camadas de linhas ou polígonos de referência
  3. Ative a ferramenta "Bounded Polygon Generator"
  4. Os polígonos serão gerados respeitando os limites do quadro
Dica: Perfeito para criar polígonos em áreas específicas, respeitando limites administrativos ou de projeto.

Point on Surface Generator

Gera pontos dentro de polígonos selecionados

Como usar:

  1. Selecione os polígonos na camada desejada
  2. Execute a ferramenta "Point on Surface Generator"
  3. Configure a camada de destino para os pontos
  4. Os pontos serão criados no centroide de cada polígono
Dica: Útil para criar pontos de referência, rótulos ou análises espaciais baseadas em centroides.

Intersection Line

Insere vértices compartilhados nas interseções de linhas

Como usar:

  1. Ative a ferramenta "Intersection Line"
  2. Desenhe uma área de seleção no mapa
  3. A ferramenta identificará todas as interseções de linhas na área
  4. Vértices compartilhados serão inseridos automaticamente
Dica: Essencial para garantir topologia correta em redes de linhas, evitando problemas de conectividade.
